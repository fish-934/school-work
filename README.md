## COM109 附属站：Trailhead Guide Console（向导工作台）

配合主站 **Trailhead**（徒步向导预约站）的后台演示，用来管理预约、排班和指派向导。

- 数据用 localStorage 模拟，没有后端、没有构建工具，双击即可运行
- 入口：`trailhead-console/index.html`
